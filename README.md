# Paperclip Alerts

The one-button page that turns on phone alerts for a private Paperclip install. It holds no secrets and no task data. The key in `index.html` is a public key: it lets this page ask for notifications, and it cannot send them. Sending needs a private key that never leaves the owner's PC.

Published with GitHub Pages at https://jbeast77.github.io/paperclip-alerts/
